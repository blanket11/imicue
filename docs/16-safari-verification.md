# Safari製品版で計測・ページ横断・実Jev接続を確認した

2026-09-26。macOSのSafari 26.4をAppleの `safaridriver` で操作し、Vanillaデモの主要動作を確認した。モック接続と実Jev接続で各5項目が成功した。PlaywrightのWebKitとは別に、Safari製品版での結果として記録する。ライブラリやデモの動作修正は不要だった。

## 通った操作と検証範囲

| 項目 | 確認した結果 |
| --- | --- |
| 同意・開始・表示計測・停止 | 未許可時と許可のみの状態では操作を記録しない。開始後に機能紹介を3秒以上表示するとqualified viewと表示時間を記録する。停止・リセット後の操作では記録が増えない |
| TOP → ガイド → TOP | 移動先では再び許可・開始してから操作記録を復元。完了したガイドは候補から除外。撤回でsessionStorageを消し、再読み込み後も完了記録が戻らない |
| ブラウザの「戻る」 | 許可状態を復元せず、再び許可・開始した後に移動先で追加した完了記録を使う |
| 判定サーバー接続 | 許可・開始前は判定リクエストなし。機能紹介のクリックと検索例の操作で機能ガイドを推薦。カードと登録済みリンクを表示し、同意撤回で記録と表示を消す |
| 横方向のはみ出し | TOPと機能ガイドを1280×848px、640×848pxのviewportで確認し、横方向のはみ出しなし |

画面幅は実際の `innerWidth` と `innerHeight` を記録した。640px幅もデスクトップSafariのウィンドウであり、iPhoneのエミュレーションではない。画面キャプチャでも推薦カードと狭い幅の配置を確認した。

実APIは合成データで1回だけ呼び、HTTP 200、モデル `jev-1.13.0`、機能ガイドの推薦を確認した。入力1,822トークン、出力52トークン、HTTP呼び出しとusage読み取りを含む時間は517.79ms。単発の測定なので、速度の保証には使わない。

## 再現コマンド

macOSでSafariのWebDriverを利用可能にし、別ターミナルで `npm run dev` を起動する。通常の試験ではさらに `npm run dev:server` でモックサーバーを起動する。

```sh
npm run test:safari
```

実Jevを試す場合は、5193番ポートのモックサーバーを停止し、Git管理外の `.env.local` に `TYPESAFE_API_KEY` を設定して実行する。

```sh
RUN_SAFARI_JEV=1 node --env-file=.env.local --import tsx --conditions=imicue-source scripts/safari-smoke.ts
```

実APIを呼ぶ上限は1回で、再試行は行わない。試験用サーバーはコマンド終了時に停止する。モック接続へ戻すには `npm run dev:server` を再度起動する。

試験コマンドは5199番ポートでsafaridriverを起動し、専用のSafariセッションだけを操作・終了する。既に5199番ポートでサービスが動いている場合は試験を開始しない。設定を自動変更したり、通常の閲覧タブを操作したりしない。

実行結果とページのキャプチャはGit管理外の `test-results/safari-mock/` と `test-results/safari-jev/` に保存する。レポートには確認項目、実際のviewport、判定、API使用量を残し、認証ヘッダー・キー・生のエラー本文は残さない。

## 今回確認していないもの

対象は開発サーバーのVanillaデモと合成データ。Safari製品版ではNext.js例、単体配布ファイル、通信障害の注入、全ネットワーク・コンソールイベント収集、アクセシビリティの網羅検査、性能指標の測定を実施していない。これらをSafariで成功した項目には数えない。

iPhone/iPad実機、端末のsleep、別バージョンのSafariも未確認。既存のChromium・Firefox・WebKitのE2E84件は前回の結果を維持し、今回再実行していない。追加スクリプトの型検査・lintと、単体／統合テスト229件は成功した。

npm公開、デプロイ、DNS設定、実サイトへの導入、Issue・Project変更は行っていない。残る公開前の確認は[公開準備](12-release-preparation.md)を参照する。
