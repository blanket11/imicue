# ローカルでPACELETを試す

[READMEの準備手順](../../README.md#ローカルデモを動かす)を済ませ、リポジトリのルートで起動します。

```sh
npm run dev
```

[PACELET](http://127.0.0.1:5183/)を開き、製品紹介をスクロールしてください。閲覧記録に応じて、機能・事例・資料請求・お問い合わせへの案内が右下に出ます。APIキーは不要です。計測は自動で始まり、記録は同じタブで30分保持します。

[製品サイトデモの手順](product-demo.md)には、案内ごとの確認方法、ページ移動と保存、フォームの完了表示、Debugの操作をまとめています。記録が少ない場合や候補が拮抗する場合は見送るため、案内が常に出るわけではありません。

## 起動先を確認する

| コマンド | 開くURL | 内容 |
| --- | --- | --- |
| `npm run dev` | <http://127.0.0.1:5183/> | PACELET。`dev:next` も同じ起動先 |
| `npm run preview` | <http://127.0.0.1:5184/> | ビルド済みのPACELET。`preview:next` と同じ |
| `npm run dev:site` | <http://127.0.0.1:5187/> | Imicueの紹介サイト |

以前の5186番は、`npm run dev` の実行中に5183番へ転送します。保存領域も5183番に統一するため、5186番での以前の記録は引き継ぎません。各ポートを使用中の場合は、そのサーバーを停止してから起動し直してください。

紹介サイトの比較モックは、PACELETと同じ辞書に用意した閲覧記録を渡す説明用です。訪問者の表示時間やページ移動は計測しません。

## 静的ビルドを確かめる

```sh
npm run build:packages
npm run build:demo
npm run preview
```

`examples/next-static/out` を配信します。静的出力でも自動案内とフォームの完了表示を試せます。実フォーム送信や判定用APIは含みません。

SDKの互換APIや100候補を個別に検証する場合は、[開発用の回帰確認画面](development-fixtures.md)を使ってください。通常のデモとは別のコマンドで起動します。
