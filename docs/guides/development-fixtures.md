# SDKの開発用画面で回帰を確認する

互換API、100候補、開始モードなどを個別に検証する開発者向けの画面です。通常の製品サイトデモは [PACELET](product-demo.md)を使います。以下の画面は `npm run dev` では起動しません。

```sh
npm run dev:fixtures
```

ソースは `examples/vanilla` にあります。過去のテストとの比較に使う固定の題材と辞書を維持しています。専用の5194番で起動し、PACELETの5183番とは別の保存領域を使います。

## 基本デモで計測と判定を見る

[基本デモ](http://127.0.0.1:5194/)は、読書記録アプリを題材にした架空のページです。本の検索、利用プラン、読書記録の整理を試せます。

1. 計測を許可し、「計測を開始」を押します。
2. 「読書メモの検索例を開く」を押します。
3. 確認パネルで、操作の集計、辞書の説明、候補のスコアを確認します。判定は15秒以上の間隔で行います。
4. 候補を表示し、案内先へのリンクが出ることを確認します。

この基本デモは従来の互換APIを使い、未許可の間は計測しません。停止すると直近の記録を維持し、同意撤回とリセットは記録と抑制履歴を削除します。リセット後は、計測中なら新しい記録を始めます。デモの同意操作はSDKの動作確認用です。新しい開始方式は [自動開始・手動開始・無効化のデモ](collection.md#ローカルで確かめる)で試せます。実際のサイトでは、そのサイトの方針に合わせて開始タイミングを選んでください。

## 100件の案内先を閲覧だけで試す

[100件の閲覧デモ](http://127.0.0.1:5194/catalog/)は、クリックや入力を使わず、表示した説明から案内先を選びます。100件はそれぞれ別のIDとURLを持ちます。

1. 計測を許可して開始します。
2. 1つ目の説明を、半分以上が見える状態で2秒以上表示します。
3. 2つ目の説明へスクロールし、30秒ほど表示します。
4. 「有効な閲覧」が2回以上、「クリック」「操作」が0回となり、読書メモの検索ガイドが候補に出ることを確認します。
5. 「読書記録を試す」に切り替え、再び許可・開始して同じ操作を行います。今度は読みかけの本を整理するガイドが候補になります。

同じ100件に対して、閲覧した説明に応じて案内先が変われば成功です。画面を隠したり別タブへ移ったりすると、表示時間の計測は止まります。判定は15秒以上の間隔で行うため、表示条件を満たした直後に案内が出るとは限りません。

このデモはメモリ保存です。ページを移動すると記録が消えるので、保存を試す場合は次のページ横断デモを使ってください。Jevの全件評価や容量制限については [100候補の評価記録](../21-candidate-scale.md)にまとめています。

## ページ移動後の記録を試す

[ページ横断デモ](http://127.0.0.1:5194/?storage=session)は、同じサイト・同じタブの直近30分をsessionStorageに保持します。

1. 計測を許可して開始し、「読書メモの検索例を開く」を押します。
2. 「検索ガイド」に移動します。移動直後は、まだ保存済みの記録を読み込みません。
3. 移動先でも許可・開始すると、前のページの操作を復元します。「このガイドの確認を完了」を押します。
4. トップへ戻り、再び許可・開始します。確認パネル末尾の「記録がある項目」に前の操作が残り、完了した機能ガイドが推薦候補から外れることを確認します。
5. 「同意を撤回」を押し、再読み込み後に許可・開始します。撤回前の記録が戻らなければ、保存分の削除も成功です。

同意は保存しません。ブラウザの「戻る」でページがキャッシュから復帰した場合も、最新の保存記録を扱うため再読み込みし、許可・開始を待ちます。sessionStorageを利用できない場合はページ内のメモリで動作し、画面に制約を表示します。

通常モードへ切り替えるだけでは保存分を削除しません。消す場合は、切り替え前に同意を撤回してください。モックサーバーと併用する場合は `?engine=remote&storage=session` を指定します。[サーバーの起動手順](server-and-jev.md#モックサーバーに接続する)も参照してください。

## 静的出力と検査スクリプト

```sh
npm run build:fixtures
npm run preview:fixtures
```

4173番で `dist/demo` を配信します。PlaywrightのSDK回帰試験もこの出力を使います。

`test:safari`、`test:catalog:browser`、`test:jev:browser` は5194番の開発用画面を使います。実行前に `npm run dev:fixtures` を起動してください。実APIを使う検査の有効化条件は、各スクリプトと[サーバー接続ガイド](server-and-jev.md)を確認してください。
