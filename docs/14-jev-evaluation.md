# Jev実APIとRulesのシナリオ比較

2026-09-26。許可を受け、合成12シナリオをRulesと辞書付きJevで各1回評価した。実API呼び出しは9回で、すべて成功。3件は共通ポリシーで呼び出し前に見送った。Jevは作成済み期待値の10件と一致したが、期待値の人によるレビューは未実施であり、推薦精度としては扱わない。

## 条件と再現方法

入力は既存の `packages/core/test/fixtures.ts`。固定時刻、辞書、候補除外、共通ポリシーをそろえ、Rulesと本番用のJev Adapterを順に呼び出した。Jevのモデルは `jev-1.13.0`、タイムアウトは2秒、再試行は0回。比較のためにスコア閾値やプロンプトを変更していない。

```sh
RUN_JEV_EVALUATION=1 node --env-file=.env.local --import tsx --conditions=imicue-source scripts/evaluate-jev.ts
```

Git管理外の `.env.local` に `TYPESAFE_API_KEY` を設定する。環境変数を別の方法で読み込み済みなら `RUN_JEV_EVALUATION=1 npm run eval:jev` でも実行できる。フラグやキーなしではSKIPし、成功試験とは数えない。通常の `npm test` や `npm run check` からは実APIを呼ばない。

実際の送信は最大12回。公式APIの固定エンドポイントだけを許可し、リダイレクトは拒否する。通信・応答検証の失敗で比較を打ち切る。出力先はGit管理外の `test-results/jev-evaluation.json`。候補スコア、provider confidence、HTTPステータス、所要時間、数値のトークン使用量を残し、認証ヘッダー・キー・生の応答本文・エラー本文は残さない。

### 観測の古さが判断に十分反映されなかった

「興味の変化」は、10分前の機能閲覧と直近の料金閲覧を渡す。Rulesは5分の半減期で古い観測の重みを下げ、料金を選んだ。Jevの正規化スコアは料金0.77、機能0.72。料金が上位でも差0.05は必要な0.10を満たさず、見送りになった。料金のprovider confidenceは0.68で、下限0.60を満たしている。見送りの原因はconfidence不足ではない。

「すべて弱い入力」は30分前の閲覧だけで、クリックや表示時間を伴わない。Rulesの上位スコアは0.00625、Jevは料金0.717、機能0.687だった。どちらも見送りだが、Jevは古い観測にも高い関連性を付け、候補差の小ささで見送った。

Jevには観測からの経過時間を渡しているが、Rulesのような時間減衰をコードで適用していない。今回の結果だけで新しい重みを決めず、「古い観測しかない単一テーマ」などの未使用ケースを追加し、時間をどう扱うかを検証する。RulesとJevのスコアは算出方法が異なるため、数値だけを同じ尺度として比較しない。

2026-09-26に確認した[公式のモデル料金](https://docs.typesafe.ai/models)は入力100万トークンあたり0.042米ドル、出力無料。今回の比較分の概算は **0.000525252米ドル**（12,506 ÷ 1,000,000 × 0.042）。前の疎通試験分は含めない。これは公表単価での計算であり、実際の請求額や残高は確認していない。

## 検証と残る作業

型検査・lint・単体／統合テスト218件が成功。追加した3件はモック通信のみで、観測不足時の呼び出し抑止、候補除外、使用量の数値検査、秘密情報を出力しないこと、HTTP失敗時の打ち切り、送信回数上限、送信先制限を確認した。フラグなしの `npm run eval:jev` がSKIPすることも確認した。今回の変更は評価用スクリプトと資料が中心で、UI・配布ライブラリの変更はなく、E2Eは再実行していない。

次は時間の扱いと許容する推薦結果をレビューし、未使用シナリオで検証する。ラベル中心Jevとの比較、繰り返し実行での安定性、実利用者による推薦品質・CV改善は未検証。既存holdoutも回帰試験で使用済みなので、未知データへの品質評価には使えない。

Safari製品版・モバイル実機、ブラウザから実Jevサーバーまでの通し試験、継続運用時の利用制限も残る。npm公開、デプロイ、DNS設定、実サイトへの導入、Issue・Project変更は行っていない。
